## 零、v1.1 → v2.0 核心范式转换

### v1.1 的方法论

> "数据只有 1194 张切片、病灶只占 0.1%，所以我们要砍掉大模块、降级高风险组件、用 Loss 弥补数据不足。"

这是**防御性的**——以"数据不够"为理由解释每个设计选择，本质上是在管理 reviewer 的质疑。

### v2.0 的方法论

> "小病灶 PET 合成不是 CT→PET 一步映射问题，而是极稀疏目标在解剖-频域-病灶三层松弛空间上的序列逼近问题。Diffusion 的价值不是随机采样，而是把不可直接命中的薄流形转化为一串逐渐变薄的、有梯度的松弛目标。"

这是**主动性的**——"数据不够"不再是一个需要道歉的弱点，而是方法论的自然前提：正是因为病灶稀疏，才需要序列松弛；正是因为数据有限，每个松弛维度才选择可解释的先验而非可学习的大模型。

### 核心命题

**极稀疏小病灶（0.1% 像素占比）的 CT→PET 合成不应被建模为一步 mapping，而应被建模为解剖-频域-病灶三层松弛空间上的序列逼近问题。**

## 零-B、理论基石：序列松弛逼近的形式化

### B.1 问题的本质

病灶在 192×192 = 36,864 像素中仅占约 55 个像素（0.15%）。这个目标分布 $p_{\text{data}}$ 的支撑集是一个极端稀疏的薄流形。直接学习一个从 CT 到这个薄流形的确定性映射 $f: \text{CT} \to \text{PET}$ 面临两个根本困难：

1. **梯度稀疏**：99.85% 的像素没有病灶，$f$ 的雅可比矩阵在这些区域接近零，优化信号极弱
2. **解不唯一**：CT 上形态相似的区域可能对应完全不同的 PET 代谢状态（如正常内膜 vs 微小癌灶），薄流形上的采样高度欠定

### B.2 序列松弛的定义

**Def (Relaxed Target Sequence).** 对目标分布 $p_{\text{data}}$（支撑集仅占 0.1%-0.24% 的病灶区域），构造一列松弛目标 $\{ \tilde{p}_\tau \}_{\tau=1}^{0}$，满足：

1. **厚度递减**：$\text{supp}(\tilde{p}_1) \supset \text{supp}(\tilde{p}_{0.5}) \supset \text{supp}(\tilde{p}_0) \approx \text{supp}(p_{\text{data}})$
2. **弱收敛**：$\tilde{p}_\tau \rightharpoonup p_{\text{data}}$ as $\tau \to 0$
3. **可分步学习**：每步 $\tilde{p}_\tau \to \tilde{p}_{\tau-\Delta\tau}$ 的 KL/Wasserstein 距离足够小，使得单步预测可行

标准 DDPM 的 $\tilde{p}_t = p_{\text{data}} * \mathcal{N}(0, \sigma_t^2 I)$ 是特例——仅有**各向同性高斯松弛**，对所有空间方向和频率分量均匀抹平。这正是小病灶被"扩散掉"的根本原因：各向同性噪声对高频小目标的破坏速度远快于对低频背景的破坏速度。

### B.3 本方法的松弛策略

本方法构造的是**结构化各向异性松弛**：

$$\tilde{p}_\tau = p_{\text{data}} * \mathcal{N}\left(0, \Sigma_\tau(x)\right)$$

其中 $\Sigma_\tau(x) = \text{diag}(\sigma_\tau^{\text{low}}, \sigma_\tau^{\text{mid}}, \sigma_\tau^{\text{high}})$ 是**空间变化 + 频率感知**的各向异性协方差，受三个松弛维度调制：

$$ \sigma_\tau^{\text{high}}(x) = \sigma_\tau^{\text{base}} \cdot \left(1 - \gamma \cdot E_{\text{gabor}}(x)\right) $$

$$ \sigma_\tau^{\text{mid}}(x) = \sigma_\tau^{\text{base}} \cdot \left(1 - \alpha \cdot m_{\text{organ}}(x)\right) $$

$$ \sigma_\tau^{\text{low}}(x) = \sigma_\tau^{\text{base}} $$

直观理解：

```
标准 DDPM:     各向同性高斯 → 均匀抹平所有方向 → 小病灶早期消失
RelaxedBBDM:   器官空间松弛 ⊕ 频域松弛 ⊕ 病灶任务松弛
               + 时间维度上的差异化松弛速率
               → 小病灶在扩散过程中被"保护"而非"淹没"
```

### B.4 四层松弛的对应关系

| 松弛维度 | 松弛机制 | 从什么松弛到什么 | 在模型中的载体 |
|----------|----------|-----------------|---------------|
| **时间松弛** | BBDM 桥扩散 | $\tilde{p}_1$（粗 PET 分布）→ $\tilde{p}_0$（精确 PET） | 扩散骨干 $t=T \to 0$ |
| **空间松弛** | 器官先验 | "全图任意位置" → "解剖合理区域" | Organ Prior Encoder |
| **频域松弛** | Gabor 纹理能量 | "0/1 硬病灶" → "连续频率异常检测" | Gabor Bank |
| **任务松弛** | 松弛病灶场 | "硬 mask" → "高斯热图" → "距离变换" | Tiny Hotspot Net + Segmenter |

## 三、输入层

### 3.1 训练输入

```text
x_ct      : CT HU 单窗图像              [B, 1, 192, 192]
x_3win    : CT 三窗假 RGB (供 DINOv2)    [B, 3, 192, 192]
y_pet     : 真实 PET 定量图 (BQML)       [B, 1, 192, 192]
m_lesion  : 病灶 mask                    [B, 1, 192, 192]
m_organs  : 器官 mask (6 通道 one-hot)   [B, 6, 192, 192]
mu_map    : CT→511keV 衰减图             [B, 1, 192, 192]
meta      : 临床/扫描元数据               [B, d]
```

### 3.2 推理输入

```text
x_ct, x_3win, m_organs, mu_map, meta
```

无需 `y_pet` 和 `m_lesion`。

### 3.3 预处理管线（v2.0 必做）

```
DICOM CT:
  pydicom 读取 → RescaleSlope × 像素 + Intercept → 真实 HU (float32)
  → NIfTI/HDF5 存储（不做窗口化，保留完整 HU 范围）
  → resize(192×192, bilinear)
  → 模型内部可微窗口化

DICOM PET:
  pydicom 读取 → BQML 物理值 (float32)
  → NIfTI/HDF5 存储
  → resize(192×192, bilinear)

DICOM Label:
  → binary lesion mask (0/1)

器官 mask:
  TotalSegmentator 推理 (不训练) → 6 类 one-hot
  (uterus, bladder, rectum, bone, fat, muscle/other)
```

### 3.4 三窗假 RGB（供 DINOv2 输入）

```text
Channel R: 软组织窗  WL=40,  WW=400
Channel G: 脂肪-软组织窗 WL=-50, WW=350
Channel B: 骨/盆腔结构窗 WL=300, WW=1500
```

三窗解剖互补，比单通道三复制提供更丰富的纹理信息。DINOv2 权重冻结，仅提取 `[CLS]` token 或全局 pooling → 2-4 个语义 token (dim=64)。

**主线选择**：RadImageNet 优先，DINOv2 做消融对照。

## 五、可学习 Gabor 频域分支

### 5.1 结构

```text
x_ct → Learnable Gabor Bank (32 filters, ~5K params)
     → response maps [B, 32, 192, 192]
     → 1×1/3×3 压缩
     → f_gabor1, f_gabor2
```

### 5.2 Gabor 能量图

```text
E_gabor = normalize( sqrt( Σ_i (G_i * x_ct)^2 ) )
```

### 5.3 三处注入

```text
1. 注入 Zero-Conv Adapter 浅层 (L0-L1)，帮助保持小病灶边缘/热点
2. 参与尺度感知噪声调度：E_gabor 高 → 高频噪声弱
3. 参与晚期步 loss 权重：E_gabor 高 → w_freq 高
```

### 5.4 松弛视角下的角色

Gabor 不是普通的特征增强模块，而是**频域松弛坐标系**。它将"病灶是否存在"这种极稀疏的 0/1 监督，松弛为"局部频率能量是否异常"这种连续、稠密的信号。

## 六、器官先验分支

### 6.1 Organ Prior Encoder

```text
Input:
  [m_organs, distance_maps, mu_map]
  shape: [B, 6 + 6 + 1, 192, 192]

Organ Encoder (极轻量):
  Conv 3×3, C=16                → p_org1: [B, 16, 192, 192]
  Conv 3×3, C=32, stride=2      → p_org2: [B, 32, 48, 48]
  Conv 3×3, C=64, stride=2      → p_org3: [B, 64, 24, 24]
```

### 6.2 关键设计原则

- 器官 mask 是固定先验（TotalSegmentator 推理），不是可训练参数
- 主要用于**减少膀胱/肠道/骨边缘假阳性热点**
- 不对器官 mask 做可学习 GNN——152 例不够
- 膀胱的生理性高摄取（SUV~3-5）不应被错误惩罚

### 6.3 松弛视角下的角色

器官先验不是"告诉模型病灶在哪"，而是构建一个更厚的中间松弛空间：

```
原始目标：病灶点（极稀疏）
松弛目标：病灶可能出现的解剖区域 + 需要排除的生理高摄取区域
```

即：**空间松弛 = 将"全图搜病灶"松弛为"在解剖合理区域内搜"**。

### 6.4 衰减图

```text
μ = 0.096 × (HU / 1000) + 0.096
```

纯物理映射，零参数。511keV 线性衰减系数图作为额外空间条件注入。

## 七、DINOv2 / RadImageNet 冻结语义分支

### 7.1 结构

```text
x_3win [B, 3, 192, 192]
  → resize 到模型需要尺寸 (e.g. 224)
  → frozen DINOv2 / RadImageNet
  → global pooling / class token
  → Linear projection
  → z_sem [B, 2-4, 64]
```

### 7.2 注入方式

只在 UNet bottleneck 做单头 Cross-Attention：

```text
Q = UNet_bottleneck_features
K, V = z_sem
```

不进浅层，不展开 patch token。仅提供"当前切片的粗粒度解剖/语义上下文"。

## 九、Tiny PET Segmenter（小分割器，条件启用）

### 9.1 三阶段松弛训练协议

**阶段 1：高斯热图回归**

```text
Input:   real PET [B, 1, 192, 192]
Target:  Gaussian-smoothed lesion mask (σ=6px ≈ 1.5mm)
Loss:    L1
Output:  连续热图，梯度场稠密
```

**阶段 2：距离变换回归**

```text
Input:   real PET [B, 1, 192, 192]
Target:  signed distance transform of lesion mask
Loss:    L1
Output:  比阶段 1 更接近真实 mask，仍连续
```

**阶段 3：硬分割**

```text
Input:   real PET [B, 1, 192, 192]
Target:  binary lesion mask {0, 1}
Loss:    Dice + Focal
Output:  硬分割结果
```

### 9.2 启用门槛

```
lesion recall ≥ 0.70（阶段 3 在验证集上）
false hotspot / slice 在可接受范围内
patient-level split 无泄漏
```

### 9.3 冻结后用于 L_seg

```text
synthetic PET → frozen Tiny Segmenter → seg loss
```

$L_{\text{seg}}$ 的监督信号使用阶段 2（距离变换一致性），而非阶段 3（硬 mask），以获得更稳定的梯度：

```text
L_seg = L1( seg_relaxed(syn_PET), seg_relaxed(real_PET) )
```

## 十、条件注入层：Zero-Conv Adapter

### 10.1 为什么不用完整 ControlNet

完整 ControlNet 复制 UNet Encoder（约 3M 参数），在 1194 张切片上过参数化风险高。Zero-Conv Adapter 每个 skip level 仅一个 1×1 零卷积，总参数约 5K。

### 10.2 结构

```text
cond_l = concat(
  CT feature c_l,
  organ prior p_org_l,
  gabor feature f_gabor_l,
  hotspot prior p_hotspot_l
)

adapter_l = ZeroConv_l(cond_l)

h_l = h_l + β_l(t) · adapter_l
```

### 10.3 时变注入强度 β_l(t)

设 $\tau = t/T$，$\tau=1$ 为高噪声早期，$\tau=0$ 为接近生成完成：

| 条件类型 | β 函数 | 形状 | 设计理由 |
|----------|--------|------|----------|
| 全局语义 $\beta_{\text{global}}$ | $\beta(\tau) = a_g \cdot (0.3 + 0.7\tau)$ | 早期强，晚期弱 | 高噪声阶段需要全局结构指导 |
| 空间条件 $\beta_{\text{spatial}}(l,\tau)$ | $\beta_l(\tau) = a_l \cdot (0.6 + 0.4(1-\tau))$ | 全程保持，中后期略增强 | 器官/组织空间结构在去噪各阶段都有用 |
| Gabor/局部 $\beta_{\text{local}}(\tau)$ | $\beta(\tau) = a_f \cdot (1-\tau)^\gamma$ | 早期弱，晚期强 | 病灶纹理在去噪末期才需要精细刻画 |
| DINO 语义 $\beta_{\text{semantic}}(\tau)$ | $\beta(\tau) = a_s \cdot \sin(\pi\tau)$ | 中期最强 | 语义上下文在决定"区域属于哪个器官"时最有用 |

$a_l, a_g, a_f, a_s$ 为少量可学习标量（初始化为 1.0）。$\gamma$ 建议取 1.0-2.0。

### 10.4 空间-时间耦合注入矩阵

```
            τ=1.0   τ=0.6   τ=0.25   τ=0
            (早期)  (中早期) (中晚期) (晚期)
Bottleneck  1.0      0.5     0.1      0      ← 全局语义: 只早期
L3          0.5      1.0     0.8      0.3    ← 器官结构: 中早期最强
L2          0.2      0.8     1.0      0.5    ← 组织边界: 中晚期最强
L1          0        0.3     0.8      1.0    ← 细部: 晚期最强
L0          0        0       0.6      1.0    ← 纹理(Gabor): 仅晚期
```

## 十一、扩散骨干：Scale-Adaptive BBDM U-Net

### 11.1 BBDM 桥扩散

```text
Bridge: CT-conditioned path from CT domain to PET domain

x_t = (1 - m_t) · CT + m_t · PET + σ_t · ε

m_t: 从 0→1 的桥接系数
σ_t: 与 m_t(1-m_t) 成正比的噪声项

CT 是桥的起点，PET 是桥的终点
CT 不是"普通条件"，而是端点约束
```

### 11.2 x0-pred 参数化

```text
预测目标: x_0 (干净 PET)，而非噪声 ε
理由: PET 是定量值（BQML/SUV），x0-pred 对数值稳定性更好
```

### 11.3 DDIM 20 步采样

```text
推理: 20 步 DDIM (或 DPM-Solver++)
训练: 1000 步 sigmoid beta schedule
```

### 11.4 尺度感知噪声调度

拉普拉斯金字塔 3 层分解 + Gabor 能量调制：

```python
# Step 1: Gabor 响应 → 高频能量图
E_gabor = f_gabor.abs().mean(dim=1)  # [B, 192, 192]
E_gabor = F.avg_pool2d(E_gabor, kernel_size=8)  # 空间平滑

# Step 2: 拉普拉斯金字塔分解
low, mid, high = laplacian_pyramid(y_pet, levels=3)

# Step 3: 频带级噪声差异化
σ_low(t)   = σ_base(t)           # 低频：标准噪声
σ_mid(t)   = 0.75 · σ_base(t)    # 中频：减弱 25%
σ_high(t)  = 0.45 · σ_base(t)    # 高频：减弱 55%

# Step 4: 高频 loss 的 Gabor 加权
w_high(x)  = 1 + λ_g · E_gabor(x) + λ_h · p_hotspot(x) + λ_m · m_lesion(x)
```

**设计动机**：各向同性噪声对高频小病灶的破坏速度远超对低频背景的破坏速度——病灶在扩散的早期步就被淹没。通过差异化噪声调度，让病灶区域的去噪路径更"平坦"，模型不需要从纯噪声中"凭空恢复"被彻底抹掉的小目标。

### 11.5 U-Net 结构

```text
Input:
  x_t [B, 1, 192, 192]
  time embedding t
  CT multi-scale features (via Zero-Conv Adapter)
  organ/Gabor/hotspot priors (via Zero-Conv Adapter)
  semantic tokens (via bottleneck Cross-Attn)
  metadata (via FiLM)

Backbone:
  Encoder: CNN ResBlocks
  Bottleneck: ResBlocks + tiny Cross-Attn (单头, dim=64)
  Decoder: CNN ResBlocks + skip connections

Output head:
  PET_mean  [B, 1, 192, 192]
  PET_logvar [B, 1, 192, 192]
```

## 十二、时变 Loss 体系

### 12.1 松弛阶段与时变 Loss 调度

这是 v2.0 最重要的方法创新：**Loss 按照松弛序列的阶段差异化激活**。

| 扩散阶段 | $\tau = t/T$ | 松弛目标 | 主导 Loss | Loss 权重函数 |
|----------|-------------|----------|-----------|--------------|
| 粗松弛 | [1.0, 0.6] | 全局 SUV 分布 + 器官代谢区域 | $L_{\text{low}}, L_{\text{organ}}$ | $\lambda_{\text{low}}(\tau) = \sigma(\frac{\tau-0.3}{0.1})$ |
| 中松弛 | [0.6, 0.25] | 器官关系 + 候选热点区域 | $L_{\text{organ}}, L_{\text{hotspot}}$ | $\lambda_{\text{hotspot}}(\tau) = \sin(\pi\tau)$ |
| 细松弛 | [0.25, 0] | 病灶边界 + SUV 精度 + 假阳性抑制 | $L_{\text{freq}}, L_{\text{suv}}, L_{\text{fp}}$ | $\lambda_{\text{freq}}(\tau) = \sigma(\frac{0.7-\tau}{0.1})$ |

### 12.2 Loss 项定义

```text
L_total(τ) =
    L_bbdm                                    # 扩散基础 BBDM loss
  + λ_rec · L_recon(τ)                        # L1 + MSE
  + λ_nll · L_nll(τ)                          # 异方差不确定性 NLL
  + λ_suv · λ_suv(τ) · L_roi_suv              # 病灶 SUVmax/SUVmean/TBR 误差
  + λ_topk · λ_topk(τ) · L_topk_lesion        # 病灶区域 Top-K Focal (不全图)
  + λ_freq · λ_freq(τ) · L_focal_freq         # 频域高频保真
  + λ_seg · L_seg                             # 冻结分割器一致性 (条件启用)
  + λ_fp · λ_fp(τ) · L_false_hotspot          # 非病灶/非生理区假阳性惩罚
```

### 12.3 各 Loss 的角色与激活区间

| Loss | 作用 | 在什么阶段激活 | 设计理由 |
|------|------|---------------|----------|
| $L_{\text{bbdm}}$ | 基础扩散匹配 | 全程 | 扩散模型的基础优化目标 |
| $L_{\text{recon}}$ | 像素级 L1+MSE | 全程（权重变化） | 早期关注整体，晚期关注精度 |
| $L_{\text{nll}}$ | 异方差不确定性 | 全程 | 让模型学会自行判断哪些区域不确定 |
| $L_{\text{roi\_suv}}$ | 病灶 SUV 精度 | 仅 $\tau < 0.25$ | 早期病灶区域尚未形成，SUV 约束无意义 |
| $L_{\text{topk\_lesion}}$ | 病灶区域 Top-K | 仅 $\tau < 0.25$ | 同上 |
| $L_{\text{focal\_freq}}$ | 频域高频保真 | 仅 $\tau < 0.4$ | 早期噪声大，频域约束无效 |
| $L_{\text{seg}}$ | 分割一致性 | 仅 $\tau < 0.3$ | 分割器对粗糙的中间产物无效（条件启用） |
| $L_{\text{fp}}$ | 假阳性抑制 | 仅 $\tau < 0.3$ | 早期步不应惩罚正常生理分布（条件启用） |

### 12.4 临床元数据编码

```text
DICOM metadata (PatientWeight, age, glucose, injected_dose, ...)
  → MLP (dim < 10K params)
  → FiLM (scale, shift)
  → 注入 UNet 所有层
```

## 十七、论文叙事

### 17.1 核心叙事

> **"小病灶 PET 合成不是一步映射问题，而是极稀疏目标的序列松弛逼近问题。"**

三个天然优势：

1. **病灶 0.1% → 序列松弛有强烈的临床动机**（不是刻意设计，是数据逼出来的——病灶太稀疏，不松弛就没梯度）
2. **1194 张切片 → 每个松弛维度选择可解释的先验而非可学习的大模型**（器官先验从 TotalSegmentator 来，Gabor 从频域物理来，DINO 从冻结预训练来——每个设计都有"数据不够，所以用知识替代学习"的理由）
3. **跨中心验证 → 从弱点变亮点**（现有测试集只有 3 例，必须做 ECPC-IDS 外部验证，而这本身就是高影响力论文的标志）

### 17.2 论文题目建议

> **"Relaxed Lesion-Aware Bridge Diffusion for Small-Lesion-Fidelity CT-to-PET Synthesis"**

或：

> **"Organ- and Frequency-Guided Scale-Adaptive BBDM for Small-Lesion-Aware CT-to-PET Synthesis"**

方法名：**SLMF-BBDM** (Small-Lesion Metabolic-Fidelity Brownian Bridge Diffusion)

或：**RelaxedBBDM** (Relaxed Lesion-Aware Bridge Diffusion)

### 17.3 方法部分建议结构

```
1. 问题定义：为什么小病灶合成是极稀疏目标问题
2. 序列松弛的形式化定义
3. 四层松弛：时间 / 空间 / 频域 / 任务
4. 时变机制：注入 / 噪声 / Loss 三组时变调度
5. 条件启用组件：Tiny Segmenter + L_fp
```

## 十八、v1.1 → v2.0 变更清单

| 方面 | v1.1 | v2.0 | 变更原因 |
|------|------|------|----------|
| 方法论内核 | "参数预算约束下模块取舍" | "极稀疏目标序列松弛逼近" | 从被动防御转为主动理论 |
| Mamba | 2 层 bottleneck SSM | **出局** | 用 ~1M 参数换 Mamba 不如给 Gabor 和 Hotspot |
| GAN 判别器 | 降级为极低权重消融 | **出局** | 通用真假判别器不如三种医学先验稠密化器 |
| 完整 ControlNet | 保留（减通道） | **Zero-Conv Adapter** | 3M vs 5K 参数，数据量不支撑完整 copy |
| CT 多窗输入 | 单窗（砍掉四窗） | **三窗假 RGB** | 仅供 DINOv2 输入，不直接用于扩散条件 |
| 条件注入 | 按类型分（空间/语义/全局） | **按松弛阶段 + 层级 + 时间三重调度** | 从静态分配升级为时变耦合 |
| 噪声调度 | 尺度感知（★★★★★） | **保留并理论深化** | 用 Gabor 能量调制 + Laplacian 金字塔实现 |
| Loss 调度 | 按优先级做消融 | **时变 Loss 按松弛阶段激活** | v2.0 最重要方法创新 |
| Tiny Segmenter | 验证后冻结 | **三阶段松弛训练 + 验证门槛** | 从硬 mask 逐步松弛到连续热图 |
| DINOv2 | 冻结语义 token | **三窗假 RGB 输入 + 仅 bottleneck CA** | 明确输入格式和注入范围 |
| Organ Prior | 固定 mask 拼接 | **Organ Prior Encoder (2-3 层 Conv)** | 离散 one-hot → 连续特征图 |
| Self-Conditioning | 无 | **新增** | 低成本稳定 SUV 连续性 |
| Condition Dropout | 无 | **新增** | 提升条件鲁棒性 |
| CFG | 无 | **弱 CFG 消融 (s=1.0-1.5)** | 避免医学 hallucination |
