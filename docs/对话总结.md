按数据流向从输入到输出，覆盖全部对话中涉及的所有优化方案。

六、扩散过程层（Diffusion Process）
#	优化点	来源	核心思想	难度	优先级
6.1	布朗桥扩散 (Brownian Bridge)	综述 (BBDM, CPDM)	不扩散到纯高斯噪声，而在CT→PET之间建立直接桥接路径，保留解剖结构	高	★★★★
6.2	潜空间薛定谔桥 (LASB)	对话1 + 综述	在潜空间学习源域→目标域的熵正则化最优传输路径，比标准桥更稳定	高	★★★★
6.3	残差扩散分支	RLBCD综述	不学 x→y，而学 r=y-x（跨域差异残差），残差经扩散后注入主分支	高	★★★
6.4	尺度感知噪声调度	方向三(对话1)	不同空间频率尺度使用不同噪声注入速率——小目标高频信号在forward过程中被保护更久	高	★★★★★ (最原创)
6.5	多尺度残差扩散	方向三(对话1)	低频结构用标准扩散，高频小目标用单独短扩散路径并行处理	高	★★★★
6.6	条件噪声注入 (非纯高斯起点)	综述 (SelfRDB)	从有信息的prior/bridge端点起步（如GAN粗输出+少量噪声），而非纯高斯噪声	中	★★★
6.7	流匹配 (Flow Matching)	对话1 (SOC统一框架)	用ODE确定性路径替代SDE随机路径，更少采样步骤	高	★★★
6.8	DDIM/少步采样	综述	10-20步替代1000步，强约束场景的条件后验更窄，适合确定性采样	低	必做
6.9	x0-pred / v-pred参数化	综述	预测x0或速度场v，而非噪声ε——对定量值敏感的PET任务更稳定	低	推荐
6.10	**3MSBM相空间建模（远期）**	对话2报告	将相邻切片建模为"位置+动量"的相空间对，用多边薛定谔桥同时约束空间一致性和层间连续性——视频/3D生成的降维打击武器	很高	远期探索
6.11	**BranchSBM分支生成（远期）**	对话2报告	一个CT输入→多个合理PET输出（不同代谢状态），用分支薛定谔桥建模一对多模态转换	很高	远期探索

十一、实验设计与消融策略

#	规范项	内容	来源
11.1	**Patient-level split**	必须按病例划分train/val/test，**不能按slice随机划分**。按slice划分会导致同一患者的不同切片分布在训练集和测试集中（"伪重复"），显著夸大学术显著性	对话1、综述
11.2	**统计检验规范**	病例级配对t检验或Wilcoxon signed-rank（非正态时）；bootstrap 95% CI；Cohen's d或Cliff's delta效应量；Holm-Bonferroni多重比较纠正；按体区/病灶大小/中心分层分析	对话1、综述
11.3	**L16正交实验设计**	5个二元因子 × L16正交表 → 16次实验即可估主效应，避免全因子2^5=32组合爆炸：A=Backbone(2.5D/3D latent)、B=控制分支(on/off)、C=元数据FiLM(on/off)、D=cross-attn token(on/off)、E=uncertainty head(on/off)	对话1 (progress report)
11.4	**单因素消融分组**	8组：Data-01(空间对齐重要性)、Data-02(mask质量影响)、Cond-01(条件注入点对比)、Cond-02(metadata注入方式)、Arch-01(backbone对比)、Bridge-01(桥vs条件扩散)、Fast-01(采样器对比)、XAI-01(解释工具对比)	对话1 (progress report)
11.5	**外部验证**	必须做leave-one-center-out / scanner vendor holdout / 时间外验证中的至少一种。这是区分"中级论文"和"高级论文"的关键操作——在ECPC-IDS上训练，在外部数据集(如FDG-PET-CT-Lesions)上测试泛化	对话1、综述
11.6	**样本量估算**	大效应d≈0.8 → 15-20测试病例；中效应d≈0.5 → 35-45例(论文主实验最低要求)；小效应d≈0.3 → 90-110例。非参数检验基础上增加10%-15%	对话1 (progress report)
11.7	**复现检查清单**	10项：patient-level split / CT HU恢复 / PET SUV语义固定 / 物理空间一致性 / label重采样nearest-neighbor / 离线ETL完成 / 配置+seed记录 / 主指标含ROI-SUV / 统计按病例配对 / 失败案例+置信图输出	对话1 (progress report)

十二、论文叙事与定位策略

#	叙事要点	内容	来源
12.1	**核心叙事定位**	不是"生成更逼真的PET"（中级论文），而是"生成对下分子宫内膜癌分割更有用的PET"（高级论文）——这决定了论文的贡献层级和实验设计的主线	对话1/3/4
12.2	**Cover定理作为理论动机**	在高维潜空间中，CT→PET的跨模态映射变得更易分离——解释为何latent diffusion + 全局上下文架构在理论上是合理的（写入Introduction或Method的理论动机段）	对话2
12.3	**子宫内膜癌特异性叙事**	盆腔解剖约束严格 → GNN解剖先验自然合理；病灶<1cm → 尺度感知噪声调度的动机充分；膀胱充盈导致子宫位移 → 配准联合优化的场景合理。每一个技术创新都必须绑定一个明确的临床痛点	对话1
12.4	**知乎分级对照**	水级(Loss拼接/new optimizer)→放附录或不做；中级(Top-K Focal/Focal Frequency/Mamba)→消融主体；高级(分割闭环/不确定性门控/尺度感知噪声/GNN解剖先验)→主贡献	对话4
12.5	**关键Claim设计**	论文最后的结论不是"我们的PSNR比CPDM高了0.5dB"，而是"在<1cm的小病灶上，我们的合成PET用于分割的Dice达到X，与真实PET的Y差距仅Z%——这表明合成PET在筛选场景下可以安全辅助临床决策"	对话3
12.6	**论文题目建议方向**	"{Method Name}: 面向子宫内膜癌小病灶代谢保真的{关键技术形容词}扩散模型"——技术词和临床词必须同时出现在题目中	对话1/3
