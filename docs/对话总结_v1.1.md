## 零、数据集画像（v1.1 新增）

### 0.1 硬数据

| 指标 | 值 | 对模型的意义 |
|------|-----|-------------|
| CT 切片总数 | 1,194 | 2D训练，不能做真3D |
| PET 切片总数 | 1,196 | 与CT基本一一对应 |
| 训练患者数 | 152 | 参数预算极度受限 |
| 测试患者数 | 3（26张切片） | **严重不足**，必须引入外部验证 |
| 平均切片/患者 | 7.7（中位数 7） | 纯2D训练。层间距3.75mm下2.5D有害 |
| 切片范围 | 1-22 | 患者间差异大，不依赖层间连续性 |
| 病灶占比 | 0.1%-0.24% | 极度类别不平衡，Focal Loss是生存必需品 |
| CT 分辨率 | 512×512, 3.75mm层厚 | 需 resize→192²以匹配PET |
| PET 分辨率 | 192×192, 3.27mm层厚 | 基准分辨率 |
| CT 值域 | signed 16-bit, HU (Slope=1.0, Intercept=-1024) | HU物理语义可恢复 |
| PET 值域 | signed 16-bit, BQML (Slope=0.440324) | SUV物理语义可恢复 |
| PNG 标签 | uint8, {0,255} 二值 | 非零比 ≈ 0.15%（每张切片约55个病灶像素） |
| 测试患者数 | 3 | **文档 11.6 要求 ≥35例**，差距 10× |

### 0.2 v1.1 设计原则

1. **参数预算意识**：每个新增模块必须说明参数量和所需数据量
2. **降级而非放弃**：数据不够的模块给降级方案，不直接砍掉
3. **损失函数优先**：Loss 不增加推理参数，应最激进地加
4. **测试集是硬伤**：论文级评估需要额外数据源（ECPC-IDS 公开数据集）

总共1194张切片训练，合理参数量应在 **5M-15M**（编码器部分）。

| 2.2 | **Mamba/SSM替代CNN骨干** | 对话5 | v1.1降级：**不替代全部CNN**，仅在bottleneck用2-4层轻量SSM(dim=128-256, d_state=8-16) | ~0.5-1M | ⚠️ **降级使用**，需消融验证 |

## 七、损失函数层（v1.1 重点增强）

### v1.1 原则：Loss 不增加推理参数，最适合小数据场景，应最激进添加

### 7.1 像素保真层

| # | 优化点 | 核心思想 | v1.1 判定 |
|---|--------|----------|-----------|
| 7.1.1 | **L1 + MSE 联合(x0-pred)** | L1保边缘，MSE保整体能量 | ✅ 已实现 |
| 7.1.2 | **Sinkhorn散度 / 最优传输损失** | GeomLoss直接调用。度量分布间最优传输成本。病灶0.1%→对"热点丢失"惩罚重 | ✅ **★★★ 推荐** |
| 7.1.3 | **MS-SSIM训练损失** | 多尺度结构相似性约束 | ✅ **★★ 推荐** |

### 7.2 结构保真层

| # | 优化点 | 核心思想 | v1.1 判定 |
|---|--------|----------|-----------|
| 7.2.1 | **Gradient Loss** | 约束合成PET与真实PET梯度一致 | ✅ 已实现 |
| 7.2.2 | **Focal Frequency Loss** | ICCV 2021。频域Focal加权→解决PET模糊。**<100行代码，零额外参数** | ✅ **★★★★ 核心Loss** |
| 7.2.3 | **PatchNCE对比学习损失** | ECCV 2020。CT-PET空间位置绑定。v1.1：做2D patch（不做3D），温度0.07，采样256个patch | ✅ **★★★★★ 核心Loss** |
| 7.2.4 | **配准一致性损失** | v1.1：放弃。CT/PET分辨率不一致，1194张不够联合训练配准+生成 | ❌ **放弃** |
| 7.2.5 | **结构一致性得分(SCS) Loss** | v1.1保留概念，不作为训练Loss（需要额外标注），作为评估指标 | ⚠️ **仅评估指标** |

### 7.3 代谢保真层

| # | 优化点 | 核心思想 | v1.1 判定 |
|---|--------|----------|-----------|
| 7.3.1 | **Top-K Focal Loss** | 只关注PET最亮前5%像素+Focal加权。**病灶0.1%占比下的生存必需品** | ✅ **★★★★★ 核心Loss** |
| 7.3.2 | **ROI-SUV误差** | 病灶mask内SUVmax/SUVmean/TBR的L1误差。label有病灶mask可直接用 | ✅ **必做** |
| 7.3.3 | **Background Suppression Loss** | 对背景非病灶区虚假热点额外惩罚 | ✅ **★★ 推荐** |
| 7.3.4 | **解剖一致性约束** | CT与合成PET的边缘一致性。v1.1：用Canny边缘检测做轻量约束 | ⚠️ **简化为边缘约束** |

### 7.4 分割感知闭环层

| # | 优化点 | 核心思想 | v1.1 判定 |
|---|--------|----------|-----------|
| 7.4.1 | **分割梯度反传** | 冻结分割器→梯度反传至生成器。v1.1风险：分割器在1194张切片上的泛化能力存疑，反传梯度可能有噪声 | ⚠️ **先验证分割器性能再决定** |
| 7.4.2 | **分割一致性Loss** | 合成PET经分割器→pred_mask vs true_label。同上风险 | ⚠️ **依赖7.4.1验证结果** |

### 7.5 置信校准层

| # | 优化点 | 核心思想 | v1.1 判定 |
|---|--------|----------|-----------|
| 7.5.1 | **异方差不确定性NLL** | 输出mean+logvar，NLL自适应加权。**+1通道，参数增量 <0.1%** | ✅ **★★★★ 推荐** |
| 7.5.2 | **MC采样方差一致性** | 多次MC采样→variance map与error map相关 | ✅ **★★★ 推荐**（推理时用，不增加训练成本） |
| 7.5.3 | **VAE重建误差→条件信号** | v1.1：需要训练VAE，数据不够 | ❌ **放弃** |

### 7.6 辅助层

| # | 优化点 | v1.1 判定 |
|---|--------|-----------|
| 7.6.1 | 轻量判别器辅助Loss | ⚠️ 降级：极低权重(λ=0.01)，消融验证 |

### 7.7 v1.1 Loss消融优先级（实验顺序）

```
Phase 2a: MSE (baseline)
Phase 2b: + Top-K Focal Loss      ← 病灶0.1%，最高优先级
Phase 2c: + Focal Frequency Loss  ← 解决PET模糊
Phase 2d: + PatchNCE             ← 跨模态位置绑定
Phase 2e: + Sinkhorn散度         ← 分布对齐
Phase 2f: + ROI-SUV误差          ← 临床指标约束
Phase 2g: + Heteroscedastic NLL  ← 不确定性联合输出
Phase 2h: + Background Suppression
```

| SCS | 结构一致性得分 | ✅ 论文可定义，但需标注 |
| NR-IQA | NIQE, Brisque | ✅ 补充评价 |
| 分层报告 | 按病灶大小/体区分层 | ✅ 推荐。v1.1加：**按患者层数分层**(≥8层vs≤4层) |

### v1.1 新增关键指标

| 指标 | 定义 | 动机 |
|------|------|------|

## 十二、论文叙事（v1.1 重新定位）

### 12.1 核心叙事（修订）

> 原：不是"生成更逼真的PET"，而是"生成对分割更有用的PET"  
> v1.1 **更精确的定位**：

**"在极度稀疏的标注数据下（152例训练切片，病灶占比0.1%），如何通过频域先验、尺度感知扩散和代谢保真损失三管齐下，让合成PET在小病灶检出率上逼近真实PET——并通过跨中心外部验证证明泛化性。"**

三个天然叙事优势：
1. **病灶0.1% → 尺度感知噪声调度有强烈的临床动机**（不是刻意设计，是数据逼出来的）
2. **1194张切片 → 小数据高效学习的叙事**（Mamba O(N)、轻量频域分支、冻结基础模型——每个设计选择都有"数据不够"的理由）
3. **跨中心验证 → 从弱点变亮点**（因为现有测试集只有3例，必须做外部验证，而这本身就是高影响力论文的标志）

### 12.2 论文题目建议（修订）

> "{Method Name}: 面向极度稀疏标注的子宫内膜癌小病灶代谢保真CT-to-PET扩散模型"  
> 或  
> "{Method Name}: Frequency-Aware Scale-Adaptive Diffusion for Small-Lesion-Aware CT-to-PET Synthesis with Limited Data"

## 附录A：v1.0 → v1.1 变更清单

| 模块 | v1.0 方案 | v1.1 方案 | 变更原因 |
|------|-----------|-----------|----------|
| 输入管线 | PNG为主 | **NIfTI/HDF5为主** | PNG丢失HU/BQML物理语义 |
| CT多窗输入 | 4窗并行 | **单窗(腹部软组织窗)** | 192²下resize模糊了窗间差异，4×通道参数不值得 |
| 2.5D/3D | 固定5-slice / 自适应2-5 slice | **砍掉，纯2D单层** | 3.75mm层间距下相邻切片解剖不连续，2.5D引入噪声 |
| GNN解剖图 | 可学习GCN | **固定器官mask拼接** | 152例不够训GCN |
| Mamba | 6层替代CNN骨干 | **2层轻量bottleneck** | 过参数化风险 |
| CosAE | 远期升级方向 | **放弃，由2.1覆盖** | 应用场景不匹配(Restoration≠Generation) |
| Latent Diffusion | 训VAE | **复用预训练或放弃** | 1194张不够训VAE |
| DiT | 远期 | **放弃** | 需要百万级数据 |
| 配准联合优化 | 扩散内配准 | **降级为预处理空间变换** | 数据不支撑联合训练 |
| 测试集 | 内部留出 | **ECPC-IDS外部验证(必须)** | 现有3例测试集不够 |
| L16正交实验 | 5因子16组 | **单因素5-7组消融** | 数据量不够支撑正交实验 |
| 尺度感知噪声 | ★★★★★ | **★★★★★ (升级为核心创新)** | 病灶0.1%给出强烈动机 |
| 时变条件注入 | ★★★ | **★★★ (升级)** | 零参数，天然适配小数据 |
| DSPO偏好优化 | ★★ | **放弃** | 无临床医生偏好数据 |
| 知识蒸馏 | ★★ | **放弃** | 需要大数据Teacher |
