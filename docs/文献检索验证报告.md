## 一、扩散模型核心方法（文档第六、五章）

### 1.1 BBDM: Brownian Bridge Diffusion Model

| 字段 | 内容 |
|------|------|
| **标题** | BBDM: Image-to-Image Translation with Brownian Bridge Diffusion Models |
| **作者** | Bo Li, Kaitao Xue, Bin Liu, Yu-Kun Lai |
| **发表** | CVPR 2023 |
| **链接** | https://arxiv.org/abs/2205.07680 |
| **代码** | https://github.com/xuekt98/bbdm |
| **核心贡献** | 首次将布朗桥扩散过程引入图像翻译，直接学习两个域之间的双向扩散桥接，避免扩散到纯高斯噪声，保留源域结构信息 |
| **文档对应** | 6.1 布朗桥扩散 (★★★★) |
| **验证结论** | ✅ **完全匹配**。论文文档中描述的"不扩散到纯高斯噪声，在CT→PET之间建立直接桥接路径"精确对应BBDM核心思想 |
