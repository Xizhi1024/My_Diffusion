## 1. 设计原则

### 1.1 每个优化模块必须可消融

每个模块必须满足：

- 配置文件中有独立 `enabled` 开关。
- 关闭时不改变训练主流程，只返回 NoOp 输出。
- 开启/关闭后，模型输入 shape、loss 日志、采样接口仍稳定。
- 每个模块至少有一个 shape test 和一个 ablation config test。

### 1.2 配置优先，代码不分叉

禁止为每组实验复制训练脚本。所有实验都应通过：

```bash
python scripts/train_v2.py --config configs/experiments/slmf_full.yaml --ablation no_gabor
```

或：

```bash
python scripts/train_v2.py --config configs/experiments/slmf_full.yaml --override modules.gabor.enabled=false
```

完成。

### 1.3 性能优先级

训练性能策略按优先级排序：

1. 训练时不做 DICOM 解析、不做 TotalSegmentator、不做 DINO/RadImageNet 在线推理。
2. 所有重型先验离线缓存到 `.npz` 或 sidecar tensor 文件。
3. GPU 训练默认 AMP、EMA 间隔更新、DDIM 少步评估。
4. CPU 仅用于 smoke test 和配置验证，不作为正式训练目标。
5. 每新增模块都记录参数量、显存峰值和单 epoch 时间变化。

## 4. 统一接口设计

### 4.1 `src/model/interfaces.py`

```python
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Any, Dict, Optional

import torch
import torch.nn as nn


TensorDict = Dict[str, torch.Tensor]


@dataclass
class ConditionBundle:
    maps: TensorDict = field(default_factory=dict)
    tokens: TensorDict = field(default_factory=dict)
    scalars: TensorDict = field(default_factory=dict)
    logs: Dict[str, Any] = field(default_factory=dict)

    def get_map(self, name: str) -> Optional[torch.Tensor]:
        return self.maps.get(name)

    def merge(self, other: "ConditionBundle") -> "ConditionBundle":
        self.maps.update(other.maps)
        self.tokens.update(other.tokens)
        self.scalars.update(other.scalars)
        self.logs.update(other.logs)
        return self


@dataclass
class LossContext:
    model_pred: torch.Tensor
    loss_target: torch.Tensor
    target_pet: torch.Tensor
    pred_x0: Optional[torch.Tensor]
    timesteps: torch.Tensor
    tau: torch.Tensor
    batch: Dict[str, torch.Tensor]
    condition: ConditionBundle
    pred_logvar: Optional[torch.Tensor] = None


class PriorModule(nn.Module):
    name: str = "prior"

    def forward(self, batch: Dict[str, torch.Tensor], timesteps: torch.Tensor) -> ConditionBundle:
        raise NotImplementedError


class ConditionAdapter(nn.Module):
    def forward(
        self,
        noisy_x: torch.Tensor,
        raw_condition: torch.Tensor,
        condition: ConditionBundle,
        timesteps: torch.Tensor,
    ) -> torch.Tensor:
        raise NotImplementedError


class NoiseSchedule(nn.Module):
    def add_noise(
        self,
        x0: torch.Tensor,
        noise: torch.Tensor,
        timesteps: torch.Tensor,
        condition: ConditionBundle,
    ) -> torch.Tensor:
        raise NotImplementedError


class LossTerm(nn.Module):
    name: str = "loss"

    def forward(self, ctx: LossContext) -> tuple[torch.Tensor, Dict[str, torch.Tensor]]:
        raise NotImplementedError
```

### 4.2 NoOp 约定

所有模块必须有 NoOp：

```python
class NoOpPrior(PriorModule):
    name = "noop"

    def forward(self, batch, timesteps):
        return ConditionBundle(logs={f"{self.name}/enabled": False})
```

NoOp 不是临时 hack，而是消融实验的稳定边界。关闭模块时，主训练代码不应该有额外分支。

```python
from __future__ import annotations

from copy import deepcopy
from typing import Any, Dict


def apply_dotlist_overrides(config: Dict[str, Any], overrides: Dict[str, Any]) -> Dict[str, Any]:
    out = deepcopy(config)
    for dotted_key, value in overrides.items():
        parts = dotted_key.split(".")
        cursor = out
        for part in parts[:-1]:
            cursor = cursor.setdefault(part, {})
        cursor[parts[-1]] = value
    return out
```

```python
class Registry:
    def __init__(self):
        self._items = {}

    def register(self, name, cls):
        if name in self._items:
            raise KeyError(f"{name} is already registered")
        self._items[name] = cls

    def build(self, cfg):
        cfg = dict(cfg)
        name = cfg.pop("name")
        if name not in self._items:
            raise KeyError(f"Unknown module: {name}")
        return self._items[name](**cfg)
```

- [ ] **Step 2: 实现 GaborBank 最小版本**

```python
class GaborPrior(PriorModule):
    name = "gabor"

    def __init__(self, filters: int = 32):
        super().__init__()
        self.filters = filters
        self.proj = nn.Conv2d(1, filters, kernel_size=3, padding=1, bias=False)

    def forward(self, batch, timesteps):
        ct = batch["ct"]
        feat = self.proj(ct)
        energy = feat.abs().mean(dim=1, keepdim=True)
        return ConditionBundle(maps={"gabor_feat": feat, "gabor_energy": energy})
```

- [ ] **Step 3: 实现 OrganPriorEncoder 最小版本**

```python
class OrganPrior(PriorModule):
    name = "organ_prior"

    def __init__(self, in_channels: int = 7, out_channels: int = 16):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, padding=1),
            nn.SiLU(),
            nn.Conv2d(out_channels, out_channels, 3, padding=1),
        )

    def forward(self, batch, timesteps):
        organ = batch.get("organ_mask")
        mu = batch.get("mu_map")
        if organ is None:
            ct = batch["ct"]
            organ = torch.zeros(ct.shape[0], 6, ct.shape[2], ct.shape[3], device=ct.device, dtype=ct.dtype)
        if mu is None:
            mu = torch.zeros_like(batch["ct"])
        x = torch.cat([organ, mu], dim=1)
        return ConditionBundle(maps={"organ_feat": self.net(x)})
```

```python
def tau_gate(tau: torch.Tensor, max_tau: float | None = None, min_tau: float | None = None) -> torch.Tensor:
    gate = torch.ones_like(tau, dtype=torch.float32)
    if max_tau is not None:
        gate = gate * (tau <= max_tau).float()
    if min_tau is not None:
        gate = gate * (tau >= min_tau).float()
    return gate
```

## 7. 推荐实验顺序

按以下顺序做实验，保证每一步都能归因：

| 顺序 | 实验名 | 目的 |
|---|---|---|
| 1 | `baseline` | 确认原始 CT concat + diffusion 基线 |
| 2 | `+pred_x0` | 验证 PET 定量输出是否比 pred_noise 稳定 |
| 3 | `+heteroscedastic` | 验证 mean/logvar 不确定性头 |
| 4 | `+time_varying_loss` | 验证时变 loss 是否改善小病灶 |
| 5 | `+gabor` | 验证频域先验 |
| 6 | `+scale_adaptive_noise` | 验证小目标高频保护 |
| 7 | `+organ_prior` | 验证假阳性热点抑制 |
| 8 | `+zero_adapter` | 验证轻量条件注入优于 raw concat |
| 9 | `+hotspot_prior` | 验证小病灶候选图 |
| 10 | `+bbdm_bridge` | 验证桥扩散优于普通 DDPM/DDIM |
| 11 | `+semantic_cached_tokens` | 验证冻结语义 token 是否值得保留 |

## 9. 完成标准

实现完成后必须满足：

- 任意单个模块关闭，训练和采样仍能跑通。
- `baseline`、`no_gabor`、`no_organ`、`isotropic_noise`、`ddpm_not_bbdm` 至少五组消融配置可直接运行。
- resolved config 与 run metadata 自动保存。
- smoke test 不依赖真实数据、不依赖 CUDA。
- 训练日志能区分每个 loss term 和每个模块开关。
- 评估阶段默认 DDIM 20 步，不再用 1000 步拖慢实验。
- 重型先验全部离线缓存，训练热路径不做外部模型推理。

## 10. 优先级建议

第一阶段只做框架，不急着实现所有科研模块：

1. 配置 override + registry + NoOp。
2. Dataset 可选字段与 batch 搬运。
3. LossStack。
4. Gabor + scale-adaptive noise。
5. Organ prior + ZeroConv Adapter。
6. Hotspot prior。
7. BBDM bridge。
8. Semantic cached tokens。

这样可以先把实验系统“立住”，再逐步加入方法创新。否则模块先写满，后面消融和性能归因会很痛苦。
